9. git show abcdef (5 initial chars of commit hash code to see difference what is added and deletedd in that commit)
10. git merge branchname ( merge branchname to current branch)
11. git branch -d branch_name  (delete branch branchname using -d flag)
12. git stash (when I want to store code on temporary repo as  I want that to not to git add and commit so git stash  se temp repo mein chali gyi)
13. git stash list (to get list of stashed data commits )
14. git stash apply stash_id ( to get that particular stashed data back)
Note when we have multiple stash and then we revert back stashed data , then conflict  which one will occur first , so we will decide it  manually and then git add . and git comit is necessary
15. git stash clear ( by default git stash list is not deleted even when we revert all stashed data back , we have to run this commmand to delete stash list)
16. git revert commit_id ( to revert back from commit area to local  repo area
